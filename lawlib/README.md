# Oathkeeper lawlib

Community-maintained, source-backed legal formalizations for [Oathkeeper](https://github.com/kongeskog/oathkeeper). Legal rules and cases are authored in `.oath`. The JSON kept in Git is authored metadata: source manifests, interpretation notes, review statements, coverage inventories and scenario inputs. Compiled JSON and reports are build outputs, never source.

This repository owns the legal modules and their review history. The software repository vendors an immutable source snapshot, pinned by commit and a SHA-256 inventory. Evidence bytes live in a separate verified cache; compilation and proof checking work offline without downloading PDFs. Changes here do not silently change existing proofs or applications.

## Current collection

- **Seattle / Washington / U.S.:** selected historical parking provisions and Long/Timbs holdings. One actual Long matter, five historical proof paths and two incomplete evidence contexts.
- **2025 federal IRA:** bounded pro-rata allocation estimates, plus two historical proof paths from one actual Shank matter.

Both pilots remain drafts awaiting independent community review. Coverage declarations are explicit limits, not certificates of completeness. Read each module's README, interpretation notes and source lock.

## Contribute

Anyone may propose corrections, formalizations, tests or reviews. Professional credentials are not a contribution requirement. See [CONTRIBUTING](CONTRIBUTING.md), [GOVERNANCE](GOVERNANCE.md) and [the review protocol](community/README.md).

Install the Oathkeeper 0.5.0 Python binding from the software repository, then run:

```sh
python tools/build.py                    # offline: write compiled artifacts to .build/
python tools/sources.py fetch --module seattle  # explicit, verified evidence download
python tools/check.py --fetch            # fetch any remaining evidence; audit all modules
python tools/build.py --check            # reproduce every generated byte
```

CI pins the engine release and uploads generated artifacts with the run. For source-only clones, use `git clone --depth 1 https://github.com/kongeskog/oathkeeper-lawlib.git`. Published historical revisions remain intact. See [storage and builds](docs/STORAGE.md) for offline operation, release artifacts and mirror migration. The package manifest is `oath-package.json`; changes to language or supported legal scope require explicit versioning and replay.

Original code, formalizations and annotations are Apache-2.0. Source documents retain their own rights, recorded in each `sources.lock.json`; this license does not relicense quoted or reproduced legal materials.
