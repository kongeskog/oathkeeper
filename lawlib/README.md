# Lawlib

Canonical `.oath` files use language 0.4. JSON is compiled interchange, not the authoring language. Import digests are checked by the compiler; rule versions and recorded assessments make changes inspectable.

The initial [Seattle pilot](us/wa/seattle/README.md) contains real source material and one historical litigation matter. It is incomplete and independently unreviewed. Do not infer current legal validity from a passing proof. See [contribution requirements](../CONTRIBUTING.md).
